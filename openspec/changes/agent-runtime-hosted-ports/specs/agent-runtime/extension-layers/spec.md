## Purpose

定义在不修改上游代码的前提下叠加行为的三级扩展层：会话装饰器、执行中间件与依赖转发（SymbolBinder），包括它们的组合规则、安全边界、作用域与漂移时的失败行为。

## ADDED Requirements

### Requirement: 会话装饰器可组合
会话装饰器 SHALL 实现与会话相同的接口，可任意叠加且顺序可配置。装饰器未覆写的操作 MUST 原样委托给内层会话。

#### Scenario: 只覆写执行轮次的装饰器
- **WHEN** 宿主叠加一个只覆写执行轮次的审计装饰器
- **THEN** 执行轮次经过该装饰器，中断、插话与关闭仍正常作用于内层会话

### Requirement: 上游异常映射
经异常映射装饰器传出的上游异常 SHALL 转换为运行时自有的错误类型，并 MUST 保留原始异常作为原因，使宿主无需导入上游异常类型。

#### Scenario: 映射后保留原因
- **WHEN** 上游在执行轮次时抛出运行时无法继续的异常
- **THEN** 宿主捕获运行时错误类型，其原因链中包含原始上游异常

### Requirement: 提示缓存不变量校验
启用不变量校验时，若同一会话内系统提示或工具集在未发生历史改写的情况下发生变化，运行时 MUST 报告不变量违规。

#### Scenario: 中途工具集变化
- **WHEN** 启用不变量校验，某扩展在两轮之间改变了会话的工具定义
- **THEN** 第二轮结束时报告不变量违规

### Requirement: 执行中间件遵循上游契约
运行时注册的执行中间件 SHALL 参与上游模型请求、模型执行、工具请求、工具执行四类中间件链。初始化时 MUST 校验上游中间件契约版本，版本不匹配 MUST 导致初始化失败。

#### Scenario: 契约版本不匹配
- **WHEN** 上游中间件契约版本与运行时支持的版本不同
- **THEN** 运行时初始化失败，并给出两个版本号

#### Scenario: 工具执行中间件生效
- **WHEN** 已启用运行时中间件插件，本轮执行一次工具调用
- **THEN** 工具执行中间件被调用一次，工具结果与未启用时一致

### Requirement: 请求改写守卫
经请求改写守卫包装的请求类中间件，若返回值修改了历史消息、输入、工具定义或系统提示，该修改 MUST 被丢弃并记录告警，请求 SHALL 以未修改的形式继续。

#### Scenario: 中间件试图改写历史
- **WHEN** 受守卫的模型请求中间件在返回的请求中替换了消息列表
- **THEN** 实际发往模型的消息列表与改写前一致，并记录一条告警

### Requirement: 中间件不作为安全兜底
中间件抛出异常时 SHALL 按上游约定放行后续链路，并 MUST NOT 绕过上游审批与护栏。

#### Scenario: 中间件异常时审批仍生效
- **WHEN** 工具请求中间件抛出异常，模型调用终端工具执行危险命令
- **THEN** 该命令仍进入审批流程

### Requirement: 依赖转发按读取处绑定
依赖转发 SHALL 以「上游生产代码读取的模块属性」为单位建立绑定，把闭包对外层模块的调用转发到南向接口。在模块顶层读取的绑定 MUST 在读取方模块首次导入前安装。若初始化时发现需要覆盖的顶层绑定其读取方已被导入，运行时 MUST 报告初始化顺序错误。

#### Scenario: 延迟导入读取被转发
- **WHEN** 宿主为配置读取提供自定义南向实现，上游代码在函数体内导入并调用配置读取函数
- **THEN** 调用到达宿主提供的实现

#### Scenario: 顶层读取方已导入
- **WHEN** 宿主先导入了在模块顶层读取某被覆盖符号的上游模块，再初始化运行时并覆盖该符号
- **THEN** 初始化失败并返回初始化顺序错误，指明该符号及其读取方模块

### Requirement: 未覆盖时行为等价
未提供任何自定义南向实现时，安装依赖转发后上游行为 MUST 与未安装时等价。

#### Scenario: 上游回归测试
- **WHEN** 在 Hosted 模式安装依赖转发后运行上游 `tests/agent` 与 `tests/tools`
- **THEN** 测试结果与未安装时一致

### Requirement: 覆盖作用域必须显式声明
依赖转发的覆盖作用于整个进程，包括同进程内的上游宿主以及外层模块内部的相互调用。运行时 SHALL 在初始化结果中列出被覆盖的符号，SHALL 提供恢复原实现的操作，并 MUST 保证南向 Hosted 适配器调用的是原实现而不是转发后的实现。

#### Scenario: 列出覆盖范围
- **WHEN** 宿主以自定义配置实现初始化运行时
- **THEN** 初始化结果列出全部被覆盖的配置相关符号

#### Scenario: 恢复原实现
- **WHEN** 宿主调用恢复操作
- **THEN** 被覆盖的模块属性恢复为上游原实现

#### Scenario: Hosted 适配器不递归
- **WHEN** 在未提供自定义实现的情况下，上游读取已被转发的配置函数
- **THEN** 调用经 Hosted 适配器到达上游原函数一次，不发生递归

### Requirement: 绑定漂移时显式失败
严格模式下，必需绑定的符号在上游不存在或不可调用时，初始化 MUST 失败并指明缺失的模块与符号。可选绑定缺失时 SHALL 跳过并记录告警。

#### Scenario: 必需符号被上游移除
- **WHEN** 同步上游后，某必需绑定的符号已不存在于其读取模块
- **THEN** 严格模式初始化失败，错误中包含该模块与符号名

### Requirement: 可选的上游宿主接管
通过运行时启动器启动的上游宿主 SHALL 经过会话装饰器，且不需要修改上游代码。由后台复盘、旁路提问等派生出的子 Agent MUST NOT 被重复装饰。

#### Scenario: 经启动器运行上游网关
- **WHEN** 使用运行时启动器以与上游相同的参数启动网关，并处理一条消息
- **THEN** 该轮次经过已配置的会话装饰器，网关行为与直接启动时一致

#### Scenario: 派生子 Agent 不重复装饰
- **WHEN** 经启动器运行的会话触发一次后台复盘
- **THEN** 复盘子 Agent 上的每个装饰器只生效一次
