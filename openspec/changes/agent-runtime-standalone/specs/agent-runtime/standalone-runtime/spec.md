## Purpose

定义 Standalone 模式下 AgentRuntime 的行为契约：不依赖本机 Hermes 安装与用户目录，配置由宿主下发，能力缺席时提前禁用对应工具，并保证状态隔离与审批安全。

## ADDED Requirements

### Requirement: 状态目录隔离
Standalone 运行时的全部文件写入 MUST 位于初始化时指定的实例状态目录之内，MUST NOT 在当前用户的 `~/.hermes` 下读取或写入任何文件。

#### Scenario: 写入范围
- **WHEN** 以指定状态目录初始化 Standalone 运行时，并完成一轮包含记忆写入与终端工具调用的对话
- **THEN** 新增或修改的文件全部位于该状态目录内，`~/.hermes` 下没有文件被访问或改动

### Requirement: 状态目录为进程级且只能设置一次
一个进程 SHALL 只绑定一个 Standalone 状态目录。以不同的状态目录再次初始化 MUST 返回初始化冲突错误。状态目录 MUST 在任何上游内核模块导入之前生效。

#### Scenario: 同进程第二个状态目录
- **WHEN** 进程已以目录 A 初始化，随后以目录 B 再次初始化
- **THEN** 返回初始化冲突错误，运行时仍绑定目录 A

#### Scenario: 导入顺序
- **WHEN** 宿主在初始化运行时之前已导入上游内核模块
- **THEN** 初始化失败并返回初始化顺序错误

### Requirement: 配置由宿主下发
Standalone 运行时 SHALL 仅使用宿主通过配置接口或初始化参数下发的配置与凭证。MUST NOT 读取用户目录下的配置文件或 `.env` 文件。

#### Scenario: 用户目录存在配置
- **WHEN** 当前用户的 `~/.hermes/config.yaml` 与 `~/.hermes/.env` 中配置了其他模型与密钥，宿主下发的是本地模型端点
- **THEN** 模型请求只发往宿主下发的端点，且不携带用户目录中的密钥

### Requirement: 第三方插件默认不加载
Standalone 运行时 MUST NOT 加载 pip entry-point 插件与用户插件目录中的插件，除非宿主在初始化时显式列出。

#### Scenario: 环境中安装了第三方插件
- **WHEN** 虚拟环境中安装了一个声明 `hermes_agent.plugins` entry point 的插件，宿主未列出它
- **THEN** 该插件的钩子与中间件在会话中均未被调用

### Requirement: 能力缺席时提前禁用工具集
当某项能力在 Standalone 模式下不可用时（例如定时任务、消息投递、会话存储、OAuth 类 provider），运行时 SHALL 在能力表中声明为不可用，并在开会话时禁用依赖它的工具集，使模型看不到这些工具。宿主显式请求不可用工具集时，开会话 MUST 在任何模型调用之前失败。

#### Scenario: 能力表
- **WHEN** 宿主未提供定时任务与会话存储能力，查询能力表
- **THEN** 能力表中定时任务与会话检索均为不可用

#### Scenario: 显式请求不可用工具集
- **WHEN** 宿主在启用工具集中包含定时任务工具集
- **THEN** 开会话返回能力不可用错误，且未发出模型请求

#### Scenario: 默认工具列表
- **WHEN** 宿主未指定工具集并开会话
- **THEN** 发送给模型的工具定义中不包含定时任务、消息投递与会话检索工具

### Requirement: 未提供会话存储时不写会话数据库
宿主未提供会话存储时，Standalone 运行时 MUST NOT 把对话消息写入任何会话数据库，包括状态目录内的默认数据库。

#### Scenario: 多轮对话后检查数据库
- **WHEN** 未提供会话存储，完成三轮对话
- **THEN** 状态目录内的会话数据库（若存在）不包含这三轮的任何消息

### Requirement: 模型端点探测可控
当宿主为模型提供了上下文长度等元数据时，运行时 MUST NOT 在首轮之前向模型端点发出对话接口以外的探测请求。

#### Scenario: 预置上下文长度
- **WHEN** 宿主为本地模型端点预置上下文长度并执行一轮对话
- **THEN** 该端点收到的请求只有对话接口请求

### Requirement: Standalone 模式的审批安全
Standalone 模式 MUST 满足交互契约中「每个轮次都必须建立审批面」的要求：宿主未提供交互实现时，需要审批的操作 MUST 被拒绝且不执行。

#### Scenario: 无交互实现时的危险命令
- **WHEN** Standalone 会话未提供交互通知方，模型调用终端工具执行被判定为危险的命令
- **THEN** 命令未被执行，工具结果表明操作被拒绝

### Requirement: 核心能力端到端可用
在未安装、未配置本机 Hermes 的环境中，Standalone 运行时 SHALL 支持多轮对话，以及文件读写、终端执行、记忆读写三类工具。

#### Scenario: 本地假模型端到端
- **WHEN** 在干净环境中以兼容 OpenAI 协议的本地假模型依次驱动纯对话、`read_file`、终端 `echo`、记忆写入四个轮次
- **THEN** 四个轮次均完成，工具结果分别包含文件内容、命令输出与记忆写入成功信息，记忆文件位于状态目录内
